# Privacy Policy — Emberlight Nights Uploader

*Last updated: November 2, 2026*

Emberlight Nights Uploader ("the tool") is a private desktop application used by a single operator to upload the operator's own videos to the operator's own YouTube channel. This policy explains what data the tool handles.

## Use of YouTube API Services

The tool uses **YouTube API Services** to upload videos and to read the processing and privacy status of those videos. By using the tool, the operator agrees to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

## Data the tool accesses

- **Google account authorization.** The operator signs in with Google OAuth 2.0 and grants the tool permission to upload videos to the operator's channel and to manage the operator's own YouTube content. The resulting access and refresh tokens are stored **only on the operator's own computer**, in a local file, and are never transmitted to anyone other than Google.
- **Video metadata created by the operator**: titles, descriptions, tags, thumbnails, playlists, privacy status, scheduled publish times, and the video files themselves.
- **Status information returned by YouTube** about the operator's own uploads (video ID, processing status, privacy status), kept in a local publishing log.

The tool does **not** access, collect or store any information about other YouTube users, viewers, comments, subscriptions or analytics.

## Data sharing

No data handled by the tool is shared with, sold to or disclosed to any third party. The tool does not use advertising, analytics or tracking services. No data leaves the operator's computer except the API requests sent directly to Google.

## Data retention and deletion

OAuth tokens and the publishing log are kept on the operator's computer until the operator deletes them. The operator can revoke the tool's access to the Google account at any time through the [Google security settings page](https://security.google.com/settings/security/permissions). Revoking access invalidates the stored tokens immediately.

## Cookies

The tool is a desktop application and does not use cookies. This website does not use cookies or tracking.
